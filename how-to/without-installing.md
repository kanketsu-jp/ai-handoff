# インストールせずに使う — URL を渡すだけ

> 前提: [`README.md`](../README.md) ／ 規則の正: [`SPEC.md`](../SPEC.md)

**これはプロトコルなので、インストールは要りません。**
合意が要るのは **「ルール」と「自分がどちら側か」** の 2 つだけです。

Claude のチャットでも ChatGPT でも、**URL を貼って一言添えれば始まります。**

## 依頼する側（あなたが誰かに聞きたいとき）

```
https://github.com/kanketsu-jp/ai-handoff

これを使って、◯◯さんに △△ について聞きたいです。
```

これだけです。LLM は README の冒頭で**自分が依頼する側だと判断**し、
🚨 **いきなり `REQUEST.md` を書かずに、まずあなたに質問します**（PREFLIGHT）。

うまく始まらないときは、**どちら側かを明示**します。

```
私は依頼する側です。まず PREFLIGHT から始めてください。
```

## 聞かれる側（`REQUEST.md` を渡されたとき）

ファイルを添付して、こう打つだけです。

```
このファイルは私宛の依頼です。全部読んでから、書いてあるとおりに1つずつ質問を始めてください。
```

**「全部読んでから」が要ります。** 入れないと、要約だけして終わることがあります。

ファイルの冒頭に、その LLM 宛の指示が書いてあります。URL を知らなくても成立します。

## 何が要らないか

| | |
|---|---|
| サーバ | 要らない |
| 認証・アカウント | 要らない |
| レジストリ・発見の仕組み | 要らない |
| 相手が使う LLM の種類 | 問わない |
| 実体 | **Markdown 2 枚と、規則だけ** |

## 🚨 インストールすると何が変わるか

**プロトコルの内容は同じです。** 変わるのは手数だけです。

```bash
npx skills add kanketsu-jp/ai-handoff
```

- **Skill `ai-handoff`** … 手順が呼び出される（PREFLIGHT → 書く → 見直す → 渡す → 読む）
- **`/ai-handoff <相手と用件>`** … 🚨 **PREFLIGHT から始まる**。`REQUEST.md` を先に書かない

Claude Code / OpenCode / Codex / Cursor ほかに入ります。
**入れていない相手とも、URL 経由でやり取りできます。**

## 🚨 前提が 1 つだけあります

**相手も LLM を使っていること。** 使っていない相手には成立しません。
その場合は、これまでどおり人間が文章を運ぶことになります。

逆に言えば、**LLM が当たり前になるほど、このプロトコルの前提は揃っていきます。**
